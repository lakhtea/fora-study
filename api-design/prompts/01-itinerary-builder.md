# Prompt 1: Itinerary builder with an AI writing assistant

Advisors build trip proposals with ordered days and items (hotel, activity, transfer, note), share a read-only link with the client, and use an AI assistant to draft descriptions for items. The editor must autosave, survive a refresh, and feel fast on a laptop. Design the APIs. A model answer exists in `model-answers/01-itinerary-builder.md`; don't open it until after the rep.
